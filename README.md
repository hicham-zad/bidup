# BidUp.lol 🚀

> **Pay to Rank.** No ads, no API keys, no revenue sharing. Just outbid your competition to get to the top.

## Tech Stack
- **Framework:** Next.js (App Router, Turbopack)
- **Database & Realtime:** Supabase
- **Payments:** Stripe Checkout & Webhooks
- **Styling:** Tailwind CSS v4
- **Analytics:** Vemetric
